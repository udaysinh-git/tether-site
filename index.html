Set it up

You need Node 20 or newer and a Chromium or Firefox based browser.

1

Install the host

git clone https://github.com/udaysinh-git/tether.git
cd tether && npm install && npm run build
node host/cli.js setup

setup prints your pairing key and the lines for your agents.

2

Add it to your agent

claude mcp add --scope user tether -- node /path/to/tether/host/cli.js

Codex and other MCP clients run the same command as a stdio server.

3

Load the extension

Chrome, Brave or Edge: open chrome://extensions, turn on Developer mode, load dist/chrome and paste the key. Firefox and Zen: install the signed .xpi, no key needed.

4

Check it

node host/cli.js doctor

Then ask your agent to do something in the browser.

Safety and privacy

Everything stays on your machine

Local only

The host listens on 127.0.0.1 and refuses requests from web pages, DNS rebinding included. There is no Tether server.

Paired

Agents and extensions need a key that never leaves your machine, and you can replace it any time.

Invisible to sites

The cursor and status panel live in a closed shadow root, and the extension never takes commands from pages.

You stay in charge

Pause holds every click and keystroke. Agents are told to ask before paying, sending messages or deleting anything.
