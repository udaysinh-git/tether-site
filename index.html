Questions

Questions people ask

Why not Playwright or a headless browser?
Those start a fresh browser with no logins. Tether uses the one you already have, with your sessions, extensions and cookies, so the agent can work in your ERP, your dashboards or your inbox without anyone sharing a password.
Can it see my other tabs?
No. It sees tabs you share, tabs those pages open, and tabs in a window it opened with your approval. Bypass mode opens up every tab, only when you allow it, and turns off when the browser closes.
Which browsers work?
Chrome, Brave, Edge and other Chromium browsers, and Firefox, Zen, LibreWolf, Floorp and Waterfox. In Chromium, clicks and keys arrive as real input through the debugger.
Do the styles and scripts work without Tether?
Yes. Styles are UserCSS and scripts are standard userscripts, so they install in Stylus, Tampermonkey and Violentmonkey, and you can publish them as a Gist from the settings page.
Is Tether an MCP server?
Yes. Each agent starts Tether as an ordinary stdio MCP server, and all of them share one local host that talks to your browser extension. Anything that speaks MCP can use it, including Claude Code, Codex, Cursor and Gemini CLI.
Can I suggest a feature?
Please do. Ideas come from the Tether Discord, where you can post what you want your agent to do in your browser and vote on what others asked for.
How is Tether different from Gemini in Chrome?
Gemini in Chrome is Google's assistant in a side panel. Tether gives the agent you already code with, such as Claude Code, Codex or Cursor, your browser, in Chrome or Firefox. That agent also has your repository and terminal, so one task can reproduce a bug while signed in, read the failing request, fix the code and check the fix. Tether is free, has no daily action limit of its own, and adds devtools, lasting styles and scripts, and watchers. Gemini needs no setup and works on Android. Read the full comparison.
How do I get it?
Tether is free and open source under the MIT licence. Get it from GitHub, run setup and load the extension; the Set it up section walks through it. Questions and ideas go to the Discord.
