For Claude Code, Codex and any MCP client

Let your coding agent use your own browser.

Tether hands an agent the tabs you choose, signed in as you. It reads pages, fills forms, clicks through flows, checks the network log and can restyle a site, while you watch its cursor and can pause it at any moment.

Set it up GitHub

Nothing is visible until you share it

An agent sees a tab only after you click Share this tab or approve its request. Tabs a shared page opens come along; tabs you open yourself stay yours.

Its own window

When an agent needs a browser, it asks. You get a prompt with its reason, and on approval it works in a new window of your browser with your logins. Your own tabs keep working and stay private.

The tab you're on

For "help me with this page", the agent asks for your current tab instead, or you share it from the popup.

Every tab, if you allow it

Bypass mode opens up every tab for a task that needs what you already have open. It switches off when you close the browser.

You can see what it does

The agent has its own cursor, labelled with its name, that moves to each button before it clicks or types. A small panel on the page shows its latest action, with Pause and Stop.

Pause holds every click, keystroke and navigation until you resume. When the agent reaches something only you should do, like a CAPTCHA, a code from your phone or a payment confirmation, it brings the tab forward with a message and waits for you to press Done.

The panel can be dragged anywhere, or hidden so it only appears when the agent needs you.

Reads the page the way a person would

The agent gets each page as an outline of headings, text and controls, each with a short reference it can click, type into or choose from. Every action returns the updated page, so it knows what happened.

  • Fills and submits forms, including file uploads to hidden inputs
  • Works inside cross-origin iframes such as payment and embedded forms
  • In Chrome, Brave and Edge, clicks and keys arrive as real input
  • Runs scripts even on pages with strict security policies
  • Opens, moves between and closes tabs in its window
  • Takes screenshots and reads canvas-heavy pages when the outline is thin

Ask for changes to any site

Request a change in the popup takes a note and pasted images: a screenshot of a site you like, a mockup, a sketch. Pick lets you click a part of the page and write a note about just that element.

The agent previews CSS on the live tab, checks it with a screenshot and saves it as a style that applies on every visit. When CSS isn't enough it writes a userscript. Its reply shows under your request in the popup.

Works with Tampermonkey and Stylus

Every script is a standard .user.js and every style is UserCSS, so they run in Tampermonkey, Violentmonkey and Stylus too. It goes the other way as well: install scripts and styles from Greasy Fork or userstyles.world. Each one has its own switch, and the settings page keeps a gallery with before and after screenshots that you can download, publish as a Gist or delete.

It learns how you use a site

Record saves what you click, what you fill in, the pages you open and the site's API calls. Passwords, card numbers and one-time codes are always masked, and there is no video.

Before working on a site, the agent reads a summary of its pages, the controls you actually use, the fields you fill and your usual paths, plus notes it left itself last time.

Watchers

Ask for "tell me when this drops below 2,000" or "when the results are posted" and the agent sets up a check that runs on a schedule with your cookies. Alerts come as browser notifications and, if you like, on your phone through ntfy.

Devtools for the agent

Debugging a web app works on the real session, so the agent sees the same bugs you do.

  • Every network request since sharing, with headers and bodies
  • Console output and uncaught errors
  • Cookies, including httpOnly ones
  • JavaScript in the page's own context
  • Images, blob: media, canvases, video frames and HLS or DASH streams saved to disk
  • Downloads the site produces, with their file paths

Agents

Claude Code, Codex, Cursor, Gemini CLI and any other client that speaks MCP over stdio. Several agents can share one browser at the same time, and each shows up by name.

Browsers

Chrome, Brave, Edge and other Chromium browsers, plus Firefox, Zen, LibreWolf, Floorp and other Firefox forks. Firefox builds are signed, so they stay installed.

Safety and privacy

Everything runs on your machine. Nothing is sent to a Tether server, because there isn't one.

  • The host listens on 127.0.0.1 only and refuses requests from web pages, including DNS rebinding attempts.
  • Agents and extensions need a pairing key that stays on your machine, and you can replace it at any time.
  • The extension never takes commands from web pages. Its cursor and status panel live in a closed shadow root that sites can't read.
  • Agents are told to ask before paying, sending messages or deleting anything. Treat sharing a tab like handing someone your mouse, and keep an eye on the panel when it matters.

Set it up

You need Node 20 or newer. The whole setup takes a few minutes.

  1. Install the host.
    git clone https://github.com/udaysinh-git/tether.git cd tether npm install npm run build node host/cli.js setup

    setup prints your pairing key and the lines for your agents, and registers the bridge Firefox uses.

  2. Add it to your agent. For Claude Code:
    claude mcp add --scope user tether -- node /path/to/tether/host/cli.js

    Codex and other MCP clients run the same command as a stdio server.

  3. Load the extension. In Chrome, Brave or Edge, open chrome://extensions, turn on Developer mode, choose Load unpacked and pick dist/chrome, then paste the pairing key into the popup. In Firefox and its forks, install the signed .xpi; no key is needed there.
  4. Check it.
    node host/cli.js doctor

    Then open a page and ask your agent to do something in the browser.
